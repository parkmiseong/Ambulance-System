# v5 운행 중 임무의 예상 보상 관측 — 2026-11-11

## 구현 범위

복수 환자 통제 실험에서 확인한 과거 선택 정보의 효과를 실제 엔진에서 시험할
수 있도록 관측 한 개만 추가했다. 이 실험은 실제 성능 개선을 보장하지 않는다.
생산 보상 함수, 보상 집계 구간, 할인율, 타깃 갱신 주기 등은 변경하지 않았다.

| 항목 | v3 | v4 | v5 |
|---|---|---|---|
| 실험 버전 | 3 | 4 | 5 |
| 상태 스키마 | 3 | 3 | 4 |
| 9병원 관측 차원 | 96 | 96 | 97 |
| 보상 버전 | 3 | 4 | 4 |
| 네트워크 | flat_v3 | hospital_shared_v4 | hospital_shared_v5 |
| 학습 보상 스케일 | 1 | 100 | 100 |

이전 15개 전역 특징과 병원별 9개 특징은 보존했다. 전역 인덱스 15에 다음 값을
삽입하므로 병원 블록 시작 위치만 15에서 16으로 이동한다.

```text
estimated_total_m = wait_at_dispatch_m + estimated_travel_time_at_dispatch_m
estimated_reward_m = reward_v4(estimated_total_m, KTAS_m,
                               selected_hospital_m, occupancy_before_reservation_m)
observation[15] = sum(estimated_reward_m for m in currently_active_missions) / 100
```

각 임무의 추정은 배정 시점에 고정해 `Mission.estimated_reward`에 보관한다.
실제 도착 시각·실제 보상·종료 사유를 미리 사용하지 않는다. 임무가 도착하거나
실패로 종료돼 active 목록에서 빠지면 합계에서도 빠진다. 새로 선택할 현재 환자는
아직 active가 아니므로 자기 자신의 선택 결과가 관측에 들어가지 않는다.

원래 결과 보상은 완료 때만 기존 구간 전이에 합산한다. 예측값을 보상으로
추가 지급하거나 환자별 완료 순서로 replay를 재배열하지 않는다.

## 한 요소만 다른 대조군

`--pending-reward-feature estimate`가 기본이며 예상 보상 합을 관측한다.
`--pending-reward-feature zero`는 같은 97차원·동일 네트워크의 인덱스 15만
0으로 고정한다. 나머지 특징과 보상·시드·학습 예산을 같게 두면 추가 정보의
효과를 비교할 수 있다. 모드가 manifest에 포함돼 체크포인트 파일도 분리된다.

v4의 96차원 모델과 v5의 97차원 모델은 첫 층 크기가 다르므로, v4 대비 결과만으로
특징 하나의 효과를 분리했다고 주장하지 않는다. 주된 비교는 같은 v5 구조의
estimate/zero 두 조건으로 한다. 예측값에는 실제 미래 정보가 없지만 오차가 존재한다.
배정 당시 예상 이동시간이 이후 교통·지연·이송 실패를 정확히 예측하지 못할 수 있다.

## 검증 결과

- 전체 회귀 테스트 56개 통과.
- 기존 특징 보존, 0 특징 대조군, 임무 종료 시 제거, 미래 결과 필드 미사용,
  이전 임무의 결과가 관측되기 전 특징 반영, v5 병원 순서 대응, 체크포인트 재개 검증.
- 실제 기존 v3 50회 모델은 96차원·flat_v3·보상 3으로 로딩했다.
- 실제 기존 v4 36회 모델은 96차원·hospital_shared_v4·보상 4로 로딩했다.
- 별도 `results/verification/v5_history_smoke`에서 실제 SUMO 학습 1회와
  마지막 회차 검증을 실행한 뒤, 체크포인트를 재개해 누적 2회까지 확인했다.
- 검증용 조건은 환자 발생 120초, 병상 단위 0.02, 치료 60초 등으로 짧게 조정했다.
  실제 본 학습 성능과 비교하는 실험이 아니다.
- 두 회차 전이/선택 55개가 쌓였고 실제 gradient update가 수행됐다.
  저장 상태는 97차원·hospital_shared_v5·replay 55개·epsilon 약 0.988069다.
- 선택 로그를 콜백 순서로 재구성한 55개 관측 모두 운행 중 예상 보상 합과 일치했다.
  매 에피소드 첫 선택 2개는 0, 나머지 53개는 비영(非零) 값이었다.
- 이 짧은 표본에서 환자별 예상 보상과 실제 보상의 평균 절대 오차는 약 3.560이었다.
  예측 정확도의 일반화 근거나 실제 정책 성능 개선의 근거로 사용하지 않는다.

## 다음 평가

기존 v4 학습을 이어 붙이지 않고 새 v5 실험을 시작한다. README의 18회 명령으로
estimate 조건을 학습하고, 같은 조건의 zero 대조군과 비교한다. 학습·검증에 쓰지
않은 시드의 최단시간·휴리스틱 정책도 함께 평가한다. 보상 버전은 4로 통일한다.

기존 v3/v4 모델은 계속 원래 상태 차원으로 평가할 수 있다. 상태·네트워크가
달라 v5로 `--resume`할 수는 없다. 이후 v5 재개는 동일한 모드와 설정에서만 허용한다.

이 특징 하나로 완전한 Markov 관측이 되는 것은 아니다. 임무별 목적지·위치·중증도와
전체 교통 상태를 여전히 요약하고 있으며, 실제 성능 검증 결과에 따라 추가 관측
또는 학습 방법의 통제 실험이 필요하다.
