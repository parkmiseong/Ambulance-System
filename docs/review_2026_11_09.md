## 수정

1. 실패가 늦은 성공보다 높은 점수를 얻는 보상 역전을 v4에서 수정했다.
   기본 성공 벌점은 최대 65이며 운영상 실패는 -85로 통일했다.
   v3의 원래 보상은 명시적으로 유지한다.
2. 새 학습은 병원별 공통 Q 평가기를 사용한다. 각 병원의 9개 특징과
   전역 특징, 전체 병원 특징의 평균/최소/최대값을 입력받는다.
   출력 슬롯별 병원 편향 대신 공유된 특징→Q 매핑을 학습한다.
   이는 설계 변경이며 성능 향상은 아직 입증되지 않았다.
3. 원래 보상/100을 학습 메모리에 저장한다. 모든 보상에 동일한 양의 상수를
   적용하며, 보고 보상과 순차 전이의 보상 집계 방식은 유지한다.
   정규화가 지연 보상의 기여도 문제 자체를 해결하는 것은 아니다.
4. 마지막 학습 회차의 검증 누락을 수정하고, 검증 전 저장을 유지했다.
5. 같은 실험의 신규 실행이 기존 모델을 덮어쓰지 못하도록 검사한다.
6. 부하 순환, 여러 고정 검증 부하, 후보별 선택 추적 옵션을 추가했다.
7. v3/v4 네트워크·보상·파일명을 구분하고, 기존 v3 모델의 평가를 지원한다.
   평가에 보상 버전을 명시해 두 모델을 같은 기준으로 채점할 수 있다.

- 수정 전후 모델을 같은 보상 버전·환자 스트림·여러 시드로 비교해야 한다.
- 병원별 공통 평가기와 보상 수정 각각의 효과는 별도 통제 실험이 필요하다.
- 미배정 환자의 실패와 지연 결과가 구간 보상에 합쳐지는 학습 신호는 유지했다.
  임의로 환자별 완료 순서 전이로 바꾸면 공유 대기열의 인과 순서가 깨질 수 있다.

  v4 역시 실제 강남구 수요를 보정한 모델은 아니다.
- 실제 SUMO 재현/회귀 테스트 통과는 연동 및 구현 검증이며 임상적 또는
