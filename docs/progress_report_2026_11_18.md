## 1. 연구 목적 및 진행 요약

본 프로젝트는 SUMO 도로 교통 시뮬레이션에서 환자의 중증도, 병원 접근 시간, 병원 유형별 적합도, 병상 점유율을 고려하여 이송 병원을 선택하는 강화학습 시스템입니다. 단순히 가까운 병원으로 이송하는 정책과 비교하여, 신속한 이송과 적절한 병원 선택을 함께 달성할 수 있는지 확인하는 것이 목적입니다.

현재는 환자·이송 대기열·관리 구급차·병상 상태가 하나의 시뮬레이션 시계를 공유하도록 구현했습니다. 병원 선택에는 action masking을 적용한 Double DQN을 사용하며, 웹 대시보드에서 차량 이동과 환자별 결과를 확인할 수 있습니다.

확인 시점에 누적 63회 학습, 실제 가중치 업데이트 925회가 저장되어 있습니다. 60회 모델은 고정 검증 패널 27개 조건에서 검증을 완료하여 best로 저장되었습니다. 이 검증의 환자 도착률은 95.33%, 연구용 골든타임 내 도착률은 65.11%입니다. **동일 조건의 baseline 최종 비교 결과는 아직 확보하지 못했으므로 DQN의 우월성을 주장하는 단계는 아닙니다.**

또한 SUMO 엔진 중단과 배경 구급차 경로 오류를 확인했습니다. 정상 배경 경로만 유지한 진단 사본은 동일 실패 회차를 세 번 완료했지만, 이 변경은 현재 실제 학습 입력에는 반영되지 않았습니다.

## 3. MDP 설계

### 3.1 문제 정의

의사결정 인덱스를 n이라 할 때, 설계는 `M=(S,A,P,R,γ)`로 정리할 수 있습니다.

| 구성 요소 | 구현 내용 |
|---|---|
| 에이전트 | 현재 배차 대상 환자의 이송 병원을 선택하는 DQN |
| 의사결정 시점 | 신규 이송 병원 선택 또는 도착 거절 후 재배정 시점 |
| 전체 환경 상태 S | 교통 차량·신호·환자 대기열·진행 중 임무·병상 점유 및 해제 일정 등 |
| 에이전트 관측 o | 전체 환경을 압축한 환자·대기열·진행 임무·후보 병원 특징 |
| 행동 A | 후보 병원의 인덱스 선택; 현재 최대 7개 |
| 전이 P | SUMO 차량 이동, 외생적 환자 발생, 임무 완료·실패, 입원·치료 종료, 재배정으로 구성 |
| 보상 R | 환자 이송 결과와 거절 이벤트를 기반으로 계산 |
| 할인율 γ | 0.95, 병원 선택 전이마다 적용 |
| 종료 | 발생 기간 종료 후 대기·진행 임무가 모두 정리되거나 안전 상한 도달 |

**현재 관측을 엄밀한 Markov 상태라고 단정하지 않습니다.** 모든 차량 위치·신호 상태·개별 임무 경로·병상 해제 일정 전체가 관측 벡터에 포함되지 않으므로, 부분 관측 환경을 압축 상태로 근사하여 학습하는 구조입니다. 의사결정 사이의 시간 간격도 일정하지 않아 사건 기반 SMDP 관점의 검토가 가능합니다. 현재 구현은 초 단위의 `γ^Δt` 할인을 적용하지 않습니다.

### 3.3 행동 마스킹과 대기 정책

경로가 없거나, 설정된 중증도 수용 역량에 미달하거나, 수용 불가인 병원은 마스킹합니다. 현재 연구용 수용 규칙은 다음과 같습니다.

| KTAS | 필요한 내부 병원 역량 수준 |
|---|---|
| 1~2 | 수준 3: 권역응급의료센터 |
| 3 | 수준 2 이상: 지역응급의료센터 이상 |
| 4~5 | 수준 1 이상 |

이 규칙은 임상 지침을 구현한 것으로 확정한 값이 아닌 연구용 가정입니다. 현재 저장된 병원 유형 라벨에서는 KTAS 1~2의 선택이 사실상 한 후보로 제한되는 구조도 확인되므로, 정책의 선택 여지와 병원 유형 데이터의 정확성을 점검해야 합니다.

현재 점유율이 85% 미만이어도, 새 환자 입원 후 점유율이 85%를 넘으면 수용하지 않습니다. 관리 차량이 부족하거나 일시적 병상 부족이 있으면 대기·재시도하며, 기본 대기열은 KTAS 우선, 동률이면 먼저 발생한 환자 우선입니다. 구급차 배차 순서와 경로 자체를 DQN의 행동으로 학습하는 구조는 아닙니다.

### 3.4 실제 보상 귀속 방식

학습 전이는 병원 선택 순서로 구성합니다. `r_n`은 **선택 n 이후 다음 선택 전까지 관측된 결과 보상과 거절 페널티의 합**입니다. 따라서 이전에 배정되어 아직 이동 중이던 환자의 결과도 현재 전이 보상에 포함될 수 있습니다.

즉, 현재는 환자 i의 최종 보상을 그 환자를 최초 배정한 전이에 직접 돌려주는 구조가 아닙니다. 진행 임무 예상 보상 특징은 이 불확실성을 보완하는 관측이며, 보상 귀속 문제 자체를 해결한 것은 아닙니다. 비동기 임무의 credit assignment는 주요 후속 검토 과제입니다.

## 4. 보상함수

### 4.1 정의

현재 실험은 보상 버전 4와 점유율 보상 `balanced`를 사용합니다. 성공 환자 i에 대해 다음을 정의합니다.

- `T_i`: 환자 발생부터 최종 이송 완료까지의 총 경과시간. 대기와 재이송 시간을 포함합니다.
- `L_k`: KTAS k에 설정한 연구용 시간 한계.
- `z=T_i/L_k`.
- `S_i`: 병원 유형과 Pre-KTAS 불확실성을 반영한 예상 적합도, 0~1.
- `o_i`: 최종 선택 병원의 해당 배정 시점 점유율.
- `n_i`: 실제 입원 거절 횟수.

성공 시 총보상은 다음 7개 항의 합입니다.

```text
R_i = 10·I(T_i ≤ L_k)
      − 4·min(z, 3)
      − 8·min(max(z−1, 0), 2)
      − 24·(1−S_i)²
      + 8·(1−2o_i)
      − 5·max(o_i−0.7, 0)/0.3
      − 12·n_i
```

| 항목 | 의미 및 설계 의도 |
|---|---|
| 골든타임 +10 | 설정 시간 내 도착 시 가점 |
| 시간 −4·min(z,3) | 전체 경과시간 단축 유도 |
| 초과시간 항 | 시간 한계 초과 시 추가 감점 |
| 적합도 제곱 항 | 환자와 병원 유형의 부적합 억제 |
| 점유율 항 | 50% 미만 가점, 50% 초과 감점 |
| 과밀 항 | 점유율 70% 초과 시 추가 감점 |
| 거절 −12/회 | 실제 수용 거절·재이송 부담 반영 |

시간 한계는 다음과 같으며 **공식 KTAS 골든타임 기준이 아닌 연구용 설정**입니다.

| KTAS | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|
| L_k, 초 | 120 | 180 | 240 | 300 | 360 |

### 4.2 적합도와 Pre-KTAS 불확실성

기본 적합도 표는 아래의 실험용 값입니다.

| KTAS | 권역센터 | 지역센터 | 지역기관 | 신고기관 |
|---|---:|---:|---:|---:|
| 1 | 1.00 | 0.70 | 0.05 | 0.00 |
| 2 | 1.00 | 0.90 | 0.20 | 0.00 |
| 3 | 0.90 | 1.00 | 0.70 | 0.20 |
| 4 | 0.75 | 0.90 | 1.00 | 0.85 |
| 5 | 0.65 | 0.80 | 0.95 | 1.00 |

Pre-KTAS의 확률 질량 80%를 입력 중증도에 두고, 나머지 20%를 존재하는 인접 중증도에 균등 분산하여 기대 적합도를 계산합니다. 예를 들어 KTAS 3은 2/3/4에 0.1/0.8/0.1을 부여합니다.

현재 환자 생성에서는 `pre_ktas=ktas`로 저장합니다. 위 불확실성은 적합도 기대값 계산에 적용하는 가정이며, 실제 오분류 환자를 별도로 샘플링하는 임상 혼동행렬 모형은 아닙니다.

### 4.3 실패와 검열

보상 버전 4에서 일반 이송 실패는 다음과 같이 처리합니다.

```text
R_failure = −85 − 12·n_i
85 = 3×4 + 2×8 + 24 + 8 + 5 + 20
```

일반 실패에서는 성공용 골든타임·시간·적합도·점유율 항을 0으로 초기화하고 실패 항과 거절 항만 남깁니다. 실패 보상은 기본 가중치에서 성공 보상의 하한보다 낮도록 설정한 것으로, 임상 효용을 추정한 값은 아닙니다.

안전 상한에 의한 검열에는 일반 실패 −85를 그대로 적용하지 않고 별도로 집계합니다. 거절 비용은 실제 거절 시점에 학습 보상에 반영하며, 최종 결과에 포함된 같은 거절 비용을 학습 전이에 다시 더하지 않아 중복 계산을 방지합니다.

## 5. 학습 방법

### 5.1 Double DQN

병원별 공통 scorer를 사용하는 `hospital_shared_v6` 구조입니다. 전역 특징, 전체 병원 특징의 평균·최솟값·최댓값, 해당 병원 특징을 결합하여 병원별 Q값을 산출합니다. 은닉층은 128→128, 활성화는 ReLU입니다.

다음 상태의 유효 행동 중 online network가 최댓값 행동을 선택하고, target network가 해당 행동을 평가합니다.

```text
a* = argmax_{a ∈ 유효 행동} Q_online(o_next, a)
y  = r_n/100 + 0.95·(1−done)·Q_target(o_next, a*)
```

손실은 Smooth L1(Huber)이고, 유효하지 않은 다음 병원을 target 계산에서도 제외합니다. 병원 특징 요약에서는 현재 무효 병원까지 포함하므로 이 부분은 별도 ablation 후보입니다.

| 항목 | 설정 |
|---|---:|
| 할인율 | 0.95 |
| 학습률 | 0.0005 |
| 미니배치 | 32 |
| replay 용량 | 30,000 |
| 학습용 보상 스케일 | 원보상 /100 |
| target hard sync | 실제 가중치 업데이트 200회마다 |
| 탐색 | ε-greedy |
| ε 감소 | optimizer 업데이트마다 ×0.9995, 하한 0.05 |
| gradient clipping | norm 5 |

### 5.2 체크포인트·모델 선택

full checkpoint는 가중치·타깃 네트워크·optimizer·replay·탐색률·난수 상태·누적 카운터를 저장합니다. 추가 학습은 이 체크포인트에서 이어갑니다. 웹 및 정책 비교 평가는 검증으로 선정한 best 모델을 사용합니다.

검증은 ε=0으로 고정하고 optimizer 업데이트 없이 수행합니다. best 선정 점수는 **전체 검증 환자 수로 가중한 환자당 평균 보상**입니다. 현재 저장된 패널은 9개 시나리오×3개 검증 시드로 구성됩니다.

### 6.3 비교 평가 계획

비교 정책은 최단 도로거리, 최단 예상시간, 최소 점유율, 적합도·점유율 규칙, 복합 heuristic, 예상 즉시 보상 최대화, DQN입니다. 우선 `shortest_time`, `heuristic`, `greedy_reward`, `dqn`의 비교를 진행할 계획입니다.

최종 테스트 시드는 검증 시드와 분리한 `32001,32002,32003`을 사용합니다. 동일 네트워크·시뮬레이터·수요·초기 병상·구급차·이동 규칙에서 환자별 대응 비교를 수행하고, 보상뿐 아니라 도착률·대기시간·골든타임·적합도·점유율·거절·실패를 함께 보고합니다. 동일 실험 폴더에서 baseline 최종 비교 완료 기록은 확인되지 않았습니다.

## 7. 확인된 문제와 해석상 한계

1. **SUMO native 충돌:** 기존 1.27.1과 별도 1.28.0에서 접근 위반 `0xc0000005`를 확인했습니다. native 덤프와 공식 소스 대조상 sublane 차선 변경 처리의 NULL 차로 참조 경로가 유력하지만, 정확한 최초 상태·원인 차량까지 확정하지는 못했습니다.
2. **배경 구급차 경로 오류:** 원본 180개 정의 중 107개가 현재 도로망의 긴급차 경로 검증에 실패했습니다. 오류 경로를 제외한 73대 사본은 문제의 27회차·시나리오 9·시드 10069를 세 번 모두 엔진 중단 없이 완료했습니다. 이 결과는 다른 시나리오의 안정성이나 충돌과의 직접 인과관계를 증명하지 않습니다. 현재 본 학습은 원래 입력을 사용합니다.
3. **엔진 버전 혼합 이력:** 초기 1~24회는 1.27.1, 이후 학습은 별도 1.28.0을 사용한 재개 실험입니다. 처음부터 동일 엔진으로 학습한 단일 실험과 구분하여 기록해야 합니다.
4. **모형의 현실성:** 균등 KTAS 분포, 시간당 10/15/20명, 시간 한계, 적합도 표, 환자 1명당 점유율 8%, 고정 치료 900초 등은 연구용 가정입니다. 실제 통계·임상·병상 운영 자료에 의한 보정이 필요합니다.
5. **병원 데이터 검증:** 병원 유형은 로컬 데이터의 유형 필드를 사용합니다. 현재 저장된 라벨과 실제 지정·역량의 일치 여부를 별도로 확인해야 하며, 진료과·전문의·장비 가용성까지 반영한 모형은 아닙니다.
6. **보상 귀속·관측 한계:** 비동기 임무 결과의 전이 귀속, 압축 관측의 Markov성, 선택 단위 γ=0.95의 적정성이 미검증입니다.
7. **학습 규모:** 63회라는 에피소드 수와 별개로 실제 가중치 업데이트는 925회입니다. 현재 결과만으로 수렴 또는 학습량 충분성을 선언하지 않습니다.

## 8. 향후 진행 계획

1. **환경 신뢰성 확보:** 73대 입력 조건을 추가 시나리오에서 검증하고, 실제 학습·검증·웹에 공통 적용할 경우 입력 해시와 새 signature를 분리합니다. 병원 정차 확인 실패와 차량 소실도 추적합니다.
2. **고정 조건 비교:** 현재 best와 baseline들을 분리된 테스트 시드에서 비교합니다. 모델·manifest 사본과 입력 fingerprint를 함께 보관합니다.
3. **단일 요인 실험:** γ, 보상 귀속 방식, 병원별 예상 보상·시간 여유 특징, 보상 스케일을 한 번에 하나씩 변경하여 비교합니다.
4. **학습량·반복 검토:** 실제 업데이트 수와 학습 곡선을 기준으로 학습량을 늘리고, 독립 학습 시드 42/43/44 등에서 결과 재현성을 확인합니다.
5. **모형 적합성 판단:** 장기 자원 영향에 대한 DQN의 이득이 확인되지 않으면 contextual bandit 또는 후보별 보상 회귀와 비교합니다.
