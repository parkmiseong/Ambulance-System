# 코드·출력 파일 정리 — 2026-11-16

현재 실행 경로를 확인하고 재생성 가능한 파일과 참조되지 않는 이전 코드를 정리했다. 기존 사용자 수정 사항과 모델·실험 자료는 유지했다.

## 정리 결과

| 항목 | 결과 |
|---|---:|
| 정리한 개별 파일 | 2,098개 |
| 원본 파일 크기 합계 | 3,551,242,691바이트 |
| 남겨 둔 ZIP 두 개 | 423,728,352바이트 |
| 압축본을 포함한 용량 감소 | 약 3.13GB |

| 보존한 모델·체크포인트 | 78개 |

| 통과한 회귀 테스트 | 215개 |

용량은 파일의 논리적 크기 기준이다. 작은 정리 내역 JSON과 이 문서의 크기는 위 감소량에 포함하지 않았다.

## 정리한 항목

- 완료된 실행의 SUMO 출력·입력 복사본과 텍스트 로그 2,025개를 압축한 뒤 개별 파일을 제거했다. 대상 이름은 `edgeData.xml`, `tripinfos.xml`, `stats.xml`, `output.add.xml`, `background_repeated.trips.xml` 및 `.log`다.
- 현재 코드·테스트·배포 경로에서 참조하지 않는 `CODE/gpt/`의 이전 Python 파일 14개를 압축 보관 후 제거했다.
- 루트와 CODE의 Python 캐시를 제거했다. 이전 코드 폴더의 캐시를 합쳐 `.pyc` 파일 59개를 정리했다.
- 호출부가 없는 `ambulance_sim.await_arrival()`과 `train_agent.py`의 미사용 `copy`, `numpy` import를 제거했다.
- `.gitignore`에 Python 캐시·재생성 가능한 SUMO 출력·로컬 복구 압축본의 제외 규칙을 추가했다.

## 보존한 항목

모델의 best·last·체크포인트, 실험 manifest, 환자별·에피소드별 CSV, 결과 JSON, 그래프·PDF, 스냅샷·백업 모델을 유지했다. `results/verification/`의 기존 검증 자료도 유지했다. SUMO 원본 입력, DATASET, 가상환경과 실제 실행 코드·웹·배포 파일은 정리 대상으로 삼지 않았다.

보존 대상 678개는 정리 전후 SHA-256이 일치했다. 회귀 테스트 215개를 실행한 뒤에도 다시 일치를 확인했다. 새로 생성한 테스트 임시 폴더도 제거했다.

압축본은 로컬 복구용으로 보관하며 Git에는 포함하지 않는다. 기존 실험 CSV·JSON을 사용하는 평가·비교·웹 결과 조회는 그대로 사용할 수 있다.
