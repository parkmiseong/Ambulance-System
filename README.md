# Ambulance-System
## 연구 개발 및 필요성
구급차가 환자를 어느 병원으로 이송할지 결정하는 문제는 병상 가용성, 이동 시간, 병원 별 치료 역량 등 복합 요인을 고려해야 하는 순차적 의사 결정 문제로, 단순 최단 거리 기반 이송은 최적이 아니라는 점이 보고되어 있어, 강화 학습 기반 정책 학습으로 고도화 연구 개발 필요

## 주요 연구 내용
- State : 환자 중증도•위치, 병원 별 병상•자원 현황 / Action : 이송 병원 선택 / Reward : 치료 결과•이송 시간 설계
- 최단 거리•규칙 기반 baseline 대비 RL 정책의 개선 효과 검증
- 공개 데이터 또는 시뮬레이션 환경 기반 학습 환경 구축

## 세부 목표
1. 관련 선행 연구 서베이 및 데이터 확보 방안 검토
2. MDP 정의 및 RL 학습 환경(시뮬레이터) 구축, baseline 비교 설계
3. RL 알고리즘(DQN 계열) 1차 구현 및 baseline 대비 초기 성능 비교
